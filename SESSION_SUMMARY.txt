KEY DESIGN DECISIONS
────────────────────────────────────────────────────────────────────────────
1. Optional Proposal Extraction
   → Backward compatible: old calls without requestProposal=true work unchanged
   
2. Callback-based Cost Tracking
   → Non-blocking: real-time updates without waiting for full execution
   
3. Modal for Conflict Resolution
   → Forces explicit user decision, prevents silent acceptance of wrong proposal
   
4. 4 Resolution Strategies
   → Voting (fast, simple)
   → Hierarchical (structured)
   → Meta-reasoning (intelligent)
   → User-select (manual, modal-based)

5. By-Agent Cost Breakdown
   → Helps identify resource-intensive agents for optimization
