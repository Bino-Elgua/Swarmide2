🐛 COMMON ERRORS & FIXES

ERROR: "Cannot find module 'rlmService'"
FIX: Check import path: './services/rlmService' (not '../')

ERROR: "No compression triggered"
FIX: Need 3+ phases. phaseHistory must be recorded after each phase.
     Call recordPhaseHistory() after all agents complete.

ERROR: "RLMDashboard shows 0% reduction"
FIX: Compression only works after phase 3. Need enough history.
     Check: phaseHistory.length >= 3

ERROR: "TypeError: currentSnapshot is undefined"
FIX: Snapshot is null until phase 3. Use optional chaining:
     currentSnapshot?.id instead of currentSnapshot.id

ERROR: "Type 'any' is not assignable to type 'ContextSnapshot'"
FIX: Ensure compressContextWithRLM() return type is correct.
     Check types in rlmService.ts
