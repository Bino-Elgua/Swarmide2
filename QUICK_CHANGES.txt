HOW TO USE
================================================================================

1. Start dev server:
   npm run dev

2. Navigate to http://localhost:3000

3. Select some agents in the sidebar

4. Click the yellow ⚙️ sliders button next to any agent

5. Edit parameters in the modal:
   - Change model name
   - Change provider (Google → OpenAI)
   - Adjust reasoning depth
   - Tune personality

6. Click Save to apply changes

7. Agent uses new settings on next execution

================================================================================
TECHNICAL DETAILS
================================================================================

State Management:
  agentEditorOpen: boolean
    → Controls modal visibility
  
  editingAgent: Agent | null
    → Currently editing agent data
    → Passed to AgentEditor component

Event Handlers:
  onEditAgent: (agent: Agent) => void
    → Triggered when user clicks edit button
    → Sets editingAgent & opens modal
  
  onSave: (updatedAgent: Agent) => void
    → Updates agent in registry
    → Updates agent in project.agents if orchestrated
    → Closes modal

Modal Behavior:
  - Fixed position overlay (z-50)
  - Dark background with blur
  - Closes on Save/Cancel/X button
  - Prevents body scroll while open

================================================================================
TROUBLESHOOTING
================================================================================

Q: Edit button doesn't appear
A: Make sure agents are in the sidebar list. Click agent names first.

Q: Modal won't close
A: Click Save, Cancel, or the X button. One must close it.

Q: Changes don't apply
A: Click the Save button. Changes only apply on save.

Q: Model names wrong
A: Type the exact model ID (e.g., gpt-4o, claude-3-5-sonnet)
