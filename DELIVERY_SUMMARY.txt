HOW TO USE
================================================================================

1. Start Dev Server
   $ npm run dev
   → http://localhost:3000

2. Open Mission Settings
   Click gear icon (bottom-right)
   → Expand "Cost & Conflicts" section

3. Configure Phase 1
   Budget: $5.00
   Strategy: Voting

4. Run Example
   Prompt: "Build a SaaS dashboard"
   Agents: Select Kernel + Scale (2 agents)
   Click: Orchestrate

5. Watch Execution
   • Agents run in parallel
   • See real-time costs in CostTracker
   • Conflict modal appears if proposals differ
   • Select winning proposal
   • See resolution logged in terminal
