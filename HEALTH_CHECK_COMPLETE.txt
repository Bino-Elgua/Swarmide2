ARCHITECTURE
================================================================================

Health Check Flow:
  App Component
  └─ HealthMonitor (renders)
     └─ healthCheck.runFullCheck()
        ├─ checkAPIKey()
        ├─ checkGeminiAPI() [with 60s cache]
        ├─ checkLocalStorage()
        ├─ checkNetwork()
        └─ checkMemory()
        └─ Displays UI with status colors & latencies

API Error Handling Flow:
  Your Code
  └─ withErrorHandling('service', 'method', fn)
     └─ apiErrorHandler.executeWithRetry()
        ├─ Attempt 1 → Fail → Log warning
        ├─ Wait 1000ms → Attempt 2 → Fail → Log warning
        ├─ Wait 2000ms → Attempt 3 → Fail → Log warning
        ├─ Wait 5000ms → Attempt 4 → Fail → Throw error
        └─ Log error with full context
        └─ APIMonitor shows call in history

================================================================================
HEALTH STATUS LEVELS
================================================================================

HEALTHY (🟢):
  - All 5 health checks: OK
  - No errors
  - Any number of warnings (info only)
  - API success rate: 90%+

DEGRADED (🟡):
  - 1+ error OR 2+ warnings
  - System continues operating
  - User notification recommended
  - Some features may be slow

UNHEALTHY (🔴):
  - 2+ errors OR 1 critical error
  - System may fail
  - User should be notified immediately
  - Consider stopping operations

================================================================================
ERROR SEVERITY LEVELS
================================================================================

CRITICAL (🔴):
  - Authentication failed
  - API key invalid
  - System shutdown required
  Action: Alert user, stop execution

HIGH (🟠):
  - API error (500, 502, 503)
  - Budget exceeded
  - Network timeout
  Action: Log & retry if possible

MEDIUM (🟡):
  - Rate limited (429)
  - Slow response
  - Partial failure
  Action: Retry with backoff

LOW (🔵):
  - Minor warning
  - Deprecated feature
  - Suboptimal choice
  Action: Log for debugging

================================================================================
TROUBLESHOOTING
================================================================================

Q: Dashboards don't appear
A: Check z-index (50), CSS loaded, browser console for errors

Q: Health checks stuck on "checking"
A: First check takes time. Results cached 60s. Wait then try again.

Q: API calls not tracked
A: Ensure calls wrapped with withErrorHandling(). Check service name.

Q: Export buttons don't work
A: Check browser allows file downloads. May be blocked by popup blocker.

Q: Memory shows "unavailable"
A: Performance API not available. Only works on Chrome/Edge.

Q: High memory usage
A: Clear old calls: apiErrorHandler.clearOldCalls()
