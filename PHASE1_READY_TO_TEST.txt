================================================================================
                      TROUBLESHOOTING
================================================================================

Problem: ConflictResolver modal not appearing
  • Check browser console (F12) for errors
  • Verify 2+ agents selected
  • Check z-index in CSS (should be 999+)
  • Try scrolling down (modal might be below fold)
  • Verify showConflictResolver state is true

Problem: Cost not tracking
  • Check API key is configured
  • Verify LLM model is responding
  • Check costCalculator.ts MODEL_PRICING
  • Look for handleCostMetric callback in logs

Problem: Proposals not showing
  • Verify geminiService.performAgentTask returns proposal
  • Check proposal extraction logic (line 449-453)
  • Ensure LLM model supports JSON output

Problem: Build fails
  • Clear cache: rm -rf dist node_modules
  • Reinstall: npm install
  • Rebuild: npm run build

Problem: Dev server won't start
  • Check port 3000 is available
  • Kill existing process: lsof -i :3000
  • Restart: npm run dev
