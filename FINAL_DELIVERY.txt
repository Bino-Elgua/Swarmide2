QUICK START (5 Minutes)
═════════════════════════════════════════════════════════════════════════════

1. Configure Environment
   $ cp .env.local.example .env.local
   # Edit and add GOOGLE_API_KEY

2. Install Dependencies
   $ npm install
   # Installs: langfuse, axios, dotenv, @supabase/supabase-js

3. Import in App
   import { appIntegration } from './services/appIntegration';
   import ExecutionEngine from './components/ExecutionEngine';

4. Initialize
   useEffect(() => {
     appIntegration.initialize();
   }, []);

5. Use in JSX
   <ExecutionEngine prompt={prompt} registry={agents} />

6. Run
   $ npm run dev
   # Opens http://localhost:1111

ARCHITECTURE
═════════════════════════════════════════════════════════════════════════════

User Input (Natural Language)
    ↓
[SpecKit] → Normalize input
    ↓
[Spec Generation] → Create formal PRD + Design + Tasks
    ↓
[Supabase] → Create session & persist
    ↓
[LightRAG] → Store context for retrieval
    ↓
[Durable Workflows] → Create execution plan with checkpoints
    ↓
[Multi-Provider] → Route to optimal LLM per phase
    ↓
[Orchestration]
    ├─→ [n8n] → Execute external workflows
    ├─→ [Langflow] → Visual orchestration
    └─→ [LLM] → Generate proposals
    ↓
[Security Validation] → Audit generated code
    ↓
[Vector DB] → Store embeddings
    ↓
[SeekDB] → Index for semantic queries
    ↓
[Langfuse] → Trace execution & track costs
    ↓
Result + Observability + Durability
