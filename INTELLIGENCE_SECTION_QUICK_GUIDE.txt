================================================================================
GETTING API KEYS
================================================================================

GEMINI (Recommended - Free):
   1. Visit: https://go.dev/genai
   2. Sign in with Google
   3. Click "Get API Key"
   4. Copy key (starts with AIza...)
   5. Paste into Logic Hub field

OPENAI (GPT-4o):
   1. Visit: https://platform.openai.com
   2. Sign in
   3. Go to API Keys
   4. Create new secret key
   5. Copy key (starts with sk-)
   6. Paste into Logic Hub field

CLAUDE (Anthropic):
   1. Visit: https://console.anthropic.com
   2. Sign in
   3. Go to API Keys
   4. Create new key
   5. Copy key (starts with sk-ant-)
   6. Paste into Logic Hub field

GROQ (Free - Fast):
   1. Visit: https://console.groq.com
   2. Sign in
   3. Create API key
   4. Copy key
   5. Paste into Logic Hub field

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Can't find Intelligence section
→ Click gear icon (⚙️) bottom-right corner
→ Scroll down in Mission Settings panel
→ Should have 🧠 brain icon

Problem: API key not working
→ Copy key completely (no extra spaces)
→ Verify correct provider
→ Check account has billing (if paid)
→ Create new key if old one revoked

Problem: Keys disappear after refresh
→ Saved in browser localStorage
→ Check browser cache isn't being cleared
→ Re-enter keys, should persist after

Problem: "Invalid API key" error
→ Wrong key format (check provider)
→ Key not for selected provider
→ Account credentials expired
→ Account billing not set up
