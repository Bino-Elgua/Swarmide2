## 🎓 Key Concepts

### Conflict Resolution
When 2+ agents propose different architectures:
1. **Voting** — Score-based winner selection
2. **Hierarchical** — Merge best ideas
3. **Meta-Reasoning** — LLM synthesizes solution
4. **User Select** — You choose

### Cost Tracking
- Real-time monitoring per agent task
- Budget constraints with warnings
- 80% warning, 100% hard limit
- Token counting accuracy ±10%

### User Control
- Set budget in Mission Settings
- Choose resolution strategy
- Review all proposals
- See costs live in dashboard
