📦 SERVICES (3 core modules, 1050+ LOC)
───────────────────────────────────────

1. ✅ Proposal Caching Service
   File: services/proposalCache.ts
   Size: 300 LOC
   Features:
     • In-memory cache with localStorage persistence
     • Cache key generation (deterministic hash-based)
     • Get/Set/Search operations
     • Success score calculation with time-decay weighting
     • TTL-based pruning (24h default, configurable)
     • Hit/miss rate tracking
     • Batch cache warmup from history
   
   Key Functions:
     - proposalCache.set(proposal, key, context?)
     - proposalCache.get(key)
     - proposalCache.findSimilar(keywords[], maxResults?)
     - proposalCache.recordEvaluation(key, outcome)
     - proposalCache.getSuccessScore(key)
     - proposalCache.getStats()
     - proposalCache.prune()
     - proposalCache.clear()

2. ✅ Custom Scoring Rubric Service
   File: services/customScoringRubric.ts
   Size: 400 LOC
   Features:
     • Default rubrics for software/science projects
     • Custom rubric generation from natural language
     • Multi-dimension scoring (alignment, technical, ethics, novelty, coherence)
     • Automatic weight normalization (sum = 1.0)
     • Proposal batch ranking and sorting
     • Rubric persistence (localStorage)
     • Flag-based warning system (identify concerns)
   
   Key Functions:
     - scoreProposalWithRubric(proposal, rubric, prompt)
     - rankProposalsWithRubric(proposals[], rubric, prompt)
     - generateCustomRubric(description, projectType)
     - getRubricForProject(projectType, customRubrics?)
     - saveRubric(), loadAllRubrics(), deleteRubric()
   
   Default Rubrics Included:
     • Software Engineering (alignment, technical, ethics, novelty, coherence)
     • Scientific Rigor (methodology, reproducibility, impact, ethics)

3. ✅ Multi-Model Synthesis Service
   File: services/multiModelSynthesis.ts
   Size: 350 LOC
   Features:
     • Support for 6 AI providers (Gemini, GPT-4o, Claude, Groq, Mistral, Perplexity)
     • Intelligent model selection by budget, role, or preference
     • Parallel model invocation (no sequential calls)
     • Ensemble voting: merge multiple model outputs intelligently
     • Consensus scoring (0-1: how much models agree)
     • Dissent identification (highlight disagreements)
     • 3 modes: cheap (fast), balanced (cost-quality), quality (best)
     • Estimated cost prediction by model
   
   Key Functions:
     - selectOptimalModels(budget?, roles?)
     - synthesizeProposalsMultiModel(proposals[], prompt, models?, budget?)
     - synthesizeCheap(proposals[], prompt, budget?)
     - synthesizeBalanced(proposals[], prompt, budget?)
     - synthesizeQuality(proposals[], prompt)
   
   Supported Models:
     • Google Gemini 3 Pro         - Fast, balanced ($0.075/$0.3 per 1k)
     • OpenAI GPT-4o              - Deep reasoning ($5/$15 per 1k)
     • Anthropic Claude 3.5 Sonnet - Nuanced ($3/$15 per 1k)
     • Groq Mixtral 8x7b          - Very fast ($0.00024 per 1k)
     • Mistral Mistral Large      - Cost-effective ($0.0048/$0.014 per 1k)
     • Perplexity Sonar Pro       - Creative ($5/$15 per 1k)
